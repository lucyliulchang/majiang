## 规格

- MP3（MPEG-1 Layer III），单声道，44.1 kHz，96 kbps（libmp3lame）。
- 时长 0.24–1.15 s（`hu` 0.97 s、`deal` 1.15 s，均在 1.5 s 内）。
- 单文件 3.2–14.2 KB，合计约 96 KB（98,455 B，≤ 400 KB）。
- 解码峰值 −6.6 ~ −2.9 dBFS（均 ≤ −1 dBFS），无直流偏移。
- 电平统一的基准为目标峰值 −3.1 dBFS；各音效相对响度由 `src/audio/soundKeys.ts` 的 `volume` 再做一次分配。

## 替换约定

后续换成真实现场录音（牌落毡面、牌墙摩擦、真人一声「胡」）时：

1. 文件名与键名保持不变（`src/audio/soundKeys.ts` 是唯一映射源）；
2. 仍需满足 08 §6：单声道 44.1 kHz、单文件 ≤ 40 KB、峰值 ≤ −1 dBFS、时长 ≤ 1.2 s（`hu`/`deal` ≤ 1.5 s）；
3. 同步更新本文件的「来源 / 生成方式 / 授权」列，**禁止**使用未授权的版权素材；
4. 若需强制刷新缓存，改文件名并在 `soundKeys.ts` 里加 `?v=`，不要依赖用户强制刷新。
