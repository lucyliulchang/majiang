# 部署（阿里云 ECS + Nginx + systemd）

目标形态：单台 ECS 上跑一个 Uvicorn 进程（同时提供 REST、WebSocket 和前端静态文件），Nginx 在最前面做 TLS 终止、反代与静态资源缓存。家庭规模（<20 用户、<3 桌）单进程足够，房间状态在内存，无需 Redis。

## 0. 前置

- 域名已解析到 ECS 公网 IP（下面以 `mj.example.com` 为例）
- 安全组放行 80 / 443（8000 只监听 127.0.0.1，不对外）
- 系统：Ubuntu 22.04 / 24.04

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip nginx sqlite3 certbot python3-certbot-nginx git curl
# 构建前端需要 Node 20（仅构建机需要，服务器上也可以只上传 dist）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
```

## 1. 建用户与目录

```bash
sudo useradd --system --create-home --home-dir /opt/mahjong --shell /usr/sbin/nologin mahjong
sudo mkdir -p /opt/mahjong/app
sudo chown -R mahjong:mahjong /opt/mahjong
```

把仓库代码放到 `/opt/mahjong/app`（`git clone` 或用 `rsync` 上传），最终结构：

```
/opt/mahjong/app/
├── backend/     # python 代码、.env、mahjong.db
└── frontend/    # dist/ 构建产物
```

## 2. 后端

```bash
sudo -u mahjong python3 -m venv /opt/mahjong/app/backend/.venv
sudo -u mahjong /opt/mahjong/app/backend/.venv/bin/pip install -r /opt/mahjong/app/backend/requirements.txt
sudo -u mahjong cp /opt/mahjong/app/backend/.env.example /opt/mahjong/app/backend/.env
```

编辑 `/opt/mahjong/app/backend/.env`：

```ini
SECRET_KEY=<python3 -c "import secrets;print(secrets.token_urlsafe(48))" 的输出>
DATABASE_URL=sqlite:///./mahjong.db
ADMIN_INIT_USERNAME=admin
ADMIN_INIT_PASSWORD=<首次启动用的强密码，创建成功后可从 .env 删掉>
TOKEN_TTL_HOURS=720
CORS_ORIGINS=https://mj.example.com
SECURE_COOKIES=true
```

要点：

- `SECRET_KEY` 一旦更换，所有已登录设备会掉线（JWT 签名失效）
- `ADMIN_INIT_PASSWORD` 只在库中没有管理员时生效；管理员已存在时该值被忽略，不会重置密码
- 数据库路径是相对 `backend/` 的 `mahjong.db`，**必须以 `backend/` 为工作目录启动**，否则会新建一个空库

## 3. 前端构建

在仓库里（本地或服务器均可）：

```bash
cd frontend
npm ci
npm run build          # 产出 frontend/dist
```

后端启动时若检测到 `frontend/dist`，会自动挂载 `/assets` 并把未知前端路由回退到 `index.html`；未匹配的 `/api/*` 返回 JSON 404。因此**不需要 Nginx 单独托管前端文件**，只要把请求转给后端即可（Nginx 仍可对 `/assets/` 开长缓存）。

## 4. systemd

`/etc/systemd/system/mahjong.service`：

```ini
[Unit]
Description=Family Mahjong (FastAPI + Uvicorn)
After=network.target

[Service]
Type=simple
User=mahjong
Group=mahjong
WorkingDirectory=/opt/mahjong/app/backend
Environment=PYTHONUNBUFFERED=1
ExecStart=/opt/mahjong/app/backend/.venv/bin/python -m uvicorn app.main:app \
    --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1
Restart=always
RestartSec=3
# 进程重启会丢进行中的那局（房态在内存），历史对局不受影响
LimitNOFILE=4096

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now mahjong
sudo systemctl status mahjong --no-pager
journalctl -u mahjong -f          # 看日志（不会打印手牌明文与密码）
curl -s http://127.0.0.1:8000/api/health   # {"ok":true,"version":"1.0.0"}
```

## 5. Nginx

`/etc/nginx/sites-available/mahjong.conf`：

```nginx
map $http_upgrade $connection_upgrade {
    default upgrade;
    ''      close;
}

server {
    listen 80;
    server_name mj.example.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name mj.example.com;

    ssl_certificate     /etc/letsencrypt/live/mj.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/mj.example.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_session_cache shared:SSL:10m;

    client_max_body_size 2m;
    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;

    # 静态资源长缓存（后端托管，文件名带 hash）
    location /assets/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # WebSocket：必须显式升级头，且关掉缓冲与超时
    location /ws {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection $connection_upgrade;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
        proxy_buffering off;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/mahjong.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

**先拿证书再启 443**：如果 `sites-enabled` 里已启用 443 但没有证书，`nginx -t` 会失败。顺序是先用 HTTP-only 配置启动 Nginx，再：

```bash
sudo certbot --nginx -d mj.example.com
```

certbot 会自动改写配置并配置续期定时器（`systemctl list-timers | grep certbot`）。

## 6. 备份

SQLite 开着 WAL，**不能直接 `cp` 主库文件**（可能拷到不一致状态），用 `.backup`：

`/opt/mahjong/backup.sh`：

```bash
#!/usr/bin/env bash
set -euo pipefail
BACKUP_DIR=/opt/mahjong/backups
STAMP=$(date +%Y%m%d-%H%M%S)
mkdir -p "$BACKUP_DIR"
sqlite3 /opt/mahjong/app/backend/mahjong.db ".backup '$BACKUP_DIR/mahjong-$STAMP.db'"
gzip -f "$BACKUP_DIR/mahjong-$STAMP.db"
# 保留最近 30 份
ls -1t "$BACKUP_DIR"/mahjong-*.db.gz | tail -n +31 | xargs -r rm -f
```

```bash
sudo chmod +x /opt/mahjong/backup.sh
sudo -u mahjong crontab -l 2>/dev/null | { cat; echo "30 3 * * * /opt/mahjong/backup.sh >> /opt/mahjong/backup.log 2>&1"; } | sudo -u mahjong crontab -
```

恢复：`sudo systemctl stop mahjong` → 解压覆盖 `backend/mahjong.db` → 删除残留的 `mahjong.db-wal` / `mahjong.db-shm` → `sudo systemctl start mahjong`。

## 7. 发版

```bash
cd /opt/mahjong/app
sudo -u mahjong git pull
sudo -u mahjong backend/.venv/bin/pip install -r backend/requirements.txt
cd frontend && sudo -u mahjong npm ci && sudo -u mahjong npm run build && cd ..
sudo systemctl restart mahjong
curl -s https://mj.example.com/api/health
```

重启会丢失进行中的牌局（内存房态）。建议家里人打完一局再发版；已结算的每局都已落库，积分不受影响。

## 8. 排障

| 现象 | 排查 |
| --- | --- |
| 页面能开但一直"重连中" | `journalctl -u mahjong` 看 WS 是否 4001/4004；确认 Nginx `/ws` 有 `Upgrade`/`Connection` 头；确认走的是 `https://` 而不是 `http://`（混合内容会被浏览器拦） |
| 刷新后掉线 | `SECRET_KEY` 是否变化过；`TOKEN_TTL_HOURS` 是否过短 |
| 登录 401 | 库是空的？首次启动是否创建了管理员（`journalctl` 里会打印一次随机密码） |
| 打开 `/room/XXX` 白屏 | `frontend/dist` 是否存在；`index.html` 回退是否生效（`curl -I https://域名/room/X` 应为 200） |
| `/api/xxx` 返回 HTML | 说明后端未更新到含"API 404 不落 SPA"的版本；升级后未匹配的 `/api/*` 会 JSON 404 |
| 分数不对 | 每局结束日志有一条结构化汇总，含生效的规则开关状态（能直接看出"这局为什么没算杠分"） |
| 数据库锁 | 确认 WAL 已开启（`sqlite3 mahjong.db "pragma journal_mode;"` → `wal`）；避免多人同时用 sqlite 客户端改库 |
