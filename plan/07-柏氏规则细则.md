## 3. 计分

### 3.1 番与底分

```
R = Σ 命中的番种番值            # 累计相加，不乘积
    同互斥组只取最高；计数型番种按"组"各计一次
不封顶，R 不做截断
B = 模板 base_score（默认 1）
U = B × R                       # 单家基准应付
```

示例：对对胡 10 番 + 清一色 30 番 = **40 番**，`U = 1 × 40 = 40`。

### 3.2 倍数

```
付款方 i 应付 = U × m_self_draw × m_dealer
```

| 倍率 | 取值 | 生效条件 |
| --- | --- | --- |
| `m_self_draw` | 2 | 自摸；点炮为 1 |
| `m_dealer` | 2 | 胡牌者是庄家（所有付款方都翻），或付款方是庄家（该家翻） |

即：**庄家胡 → 三家全部 ×2；闲家胡 → 庄家那份 ×2**；两者与自摸 ×2 **叠加**（B2）。

| 局面 | 三家各自应付 |
| --- | --- |
| 庄家自摸 | `U × 4` / `U × 4` / `U × 4` |
| 闲家自摸 | 庄家 `U × 4`，另两家 `U × 2` |
| 庄家点炮胡 | `U × 2` / `U × 2` / `U × 2` |
| 闲家点炮胡 | 庄家 `U × 2`，另两家 `U × 1` |

### 3.3 付款方

| 情形 | 付款方 |
| --- | --- |
| 自摸 | 三家各付 |
| 点炮（未触发包牌） | **三家各付**，点炮者不额外承担 |
| 点炮且触发包牌 | **点炮者一人**承担三家应付之和，另两家付 0 |
| 抢杠胡（明杠被抢） | **不走点炮**：三家各付，不乘自摸倍数，不触发包牌（§12 Q1）；被抢者的杠作废、不计杠分 |
| 荒庄（有杠） | 全 0，不罚分；已结算杠分保留 |
| 重发（无杠） | 不结算，本局作废重发 |

### 3.4 守恒

```
Σ score_delta == 0
赢家实收 == Σ(三家应付)        # 包牌只改"谁付"，不改赢家收入
```

### 3.5 算例

| # | 局面 | 番 | 各家 | 赢家 |
| --- | --- | --- | --- | --- |
| 1 | 闲家自摸（清一色 30 + 对对胡 10 + 门清 1） | 41 | 庄 `164`，闲 `82`，闲 `82` | +328 |
| 2 | 庄家自摸（对对胡 10） | 10 | 三家各 `40` | +120 |
| 3 | 闲家点炮胡（混一色 20，点炮者非庄） | 20 | 庄 `40`，点炮者 `20`，另一家 `20` | +80 |
| 4 | 闲家点炮胡且包牌（清一色 30 + 对对胡 10，点炮者非庄） | 40 | 点炮者独付 `80+40+40=160` | +160 |
| 5 | 庄家天胡 | 100 | 三家各 `400` | +1200 |

> 算例 5 说明：B2 叠加后一局封顶值很高。若家庭局觉得过重，只需改 `base_score`（如 0.5）或模板倍数，不改规则。

## 4. 庄家与轮庄

座位、抽座与局风的完整口径见 [03 §3.4](03-规则族设计.md)，柏氏无例外：

| 项 | 规则 |
| --- | --- |
| 抽座 | 每圈开始前抽座一次（北位庄家下庄即一圈结束，最少 4 局）；圈内座位不变；四人各抽风签定方位后掷 2 颗骰，点数最大者坐东位（与东位换座） |
| 首局庄家 | 抽座掷骰最大者（东位） |
| 轮庄 | 第 `n` 局庄家 = 座位 `n-1`，**不连庄**、不按胡牌者顺延 |
| 门风 | `(座位号 - 庄家座位) % 4`：**庄家恒东风**，下家南、对家西、上家北，逐局整体转动 |
| 局风 | **局序**，与庄家无关：第 1 局东风、第 2 局南风、第 3 局西风、第 4 局北风 |
| 荒庄（有杠） | 迁庄到下家，计 1 局（§9） |
| 重发（无杠） | 局号、庄家、局风、座位全部不变（§9） |
| 场与圈 | 一场 = 一圈：庄家按 `0→1→2→3` 轮转，**座位 3（北位）庄家打完下庄即圈结束**，最少 4 局；无杠重发不推进局号 |

门风用于 `men_feng_ke`（门风刻）判定，局风用于 `quan_feng_ke`（圈风刻）判定（§6.9）。门风与局风是两套坐标：庄家永远是东风，但第 2 局起局风不再是东。

## 6. 番种判定细则

### 6.1 通用前提

- 面子 = 顺子（仅数牌）| 刻子 | 杠（明/暗/补）；将 = 一对。
- 判定前先把副露（吃/碰/杠）摊入完整的 5 组结构，再求番。
- 一手牌有多解时，**逐解求番取最高总分**（与通用族一致）。
- 只对"胡牌后的完整 14 张（含副露折算）"计番，不对手牌中途计番。

### 6.2 顺子类

| 番种 | 判定 |
| --- | --- |
| 一般高 | 两组顺子数序相同、**花色不同**（如 123万 + 123条），1 番/对 |
| 姊妹花 | 两组顺子**花色、数序完全相同**（如 123万 + 123万），2 番/对 |
| 三姊妹 | 同花色存在 **三组**数序完全相同的顺子（如 123万×3），3 番 |
| 老少谱 | 同花色同时存在 123 与 789 |
| 连6 | 同花色存在 6 张连续数牌可用于组成两副相邻顺子，即 123456 / 234567 / 456789 |
| 混龙 | 123、456、789 三副齐；三副的花色集合 size ≥ 2 |
| 青龙 | 123、456、789 三副齐且全部同花色 |

**计数口径**：一般高 1 番/**对**（异花色）、姊妹花 2 番/**对**（同花色），每对独立计数。例：`123万×2 + 123条` → 姊妹花 2（万-万同花色）+ 一般高 1×2（两对万-条异花色）= **4 番**。

**三姊妹上位规则**：三姊妹固定 **3 番**（不按姊妹花叠加）。命中时其 3 副顺子不再计姊妹花/一般高，避免同一组顺子重复计。

**龙上位规则**：青龙或混龙命中时，其**组成顺子**不再参与 连6 / 老少谱 / 一般高 / 姊妹花 / 三姊妹 的计数；未参与龙的其余顺子照常计数。

例：`123 456 789 万 + 123 条 + 55 万` → 青龙 20 + 一般高 1（123万/123条，异花色）+ 混一色 20 = 41 番（连6、老少谱不计，因顺子已被龙占用）。

### 6.3 结构类与刻子类

1. **平胡**（`structure`，1 番）：4 组顺子 + 1 将，且
   - **无碰、无暗刻、无杠**（吃出来的顺子允许）；
   - 听牌形态为**两面**（胡张**不是嵌张、不是单吊、不是单边**）；
   - 将牌**不是幺（1/9）、也不是 2/5/8**，即只能是将 3/4/6/7；
   - 平胡若同时门清，另计门清 1 番（共 2 番）。
   > 听牌形态二分：**两面 → 平胡**；**嵌张/单吊/单边 → 独赢**。因此平胡与 `du_ying` 天然互斥；将牌限定 3/4/6/7 又使平胡与 `jiang_pai` 互斥。
2. **对对胡**（10 番）：4 组刻子/杠 + 将。
3. **七小对**（20 番）：14 张组成 7 对；4 张相同计为 2 对。不另设"豪华七对"。
4. **13不靠**（10 番）：
   - 共 14 张 = 将 1 对（2 张）+ 中发白 3 张 + 数牌 9 张；
   - 中发白**必须齐**，其它字牌（东南西北）不得使用；
   - 三门数牌各取 1–3 张，同门内所有牌必须落在**同一组**（147 或 258 或 369）内，不得重复同一张牌；不同门可用不同组；
   - 将牌为一对相同牌，可为任意花色（含中发白），不受分组约束；
   - 反例：同门出现 `1 8`（跨组）、`1 2`（相邻）、`1 5`（跨组）均不成立；
   - **判番范围**：13不靠 只与 `structure` 组互斥，不与任何其他番种互斥——将牌（258将/幺将）、一般高、姊妹花、三姊妹、混龙、独赢、缺门等**照常判定并累加**。13不靠 牌型本身不含顺子，故 一般高/混龙 实际不会命中；若存在特例，按"逐解取最高"处理。
5. **三暗刻 / 四暗刻**（`anke` 组）：
   - 三暗刻 10 番：4 组面子中有 ≥3 组为暗刻或暗杠（碰来的、吃来的、明杠都不算暗刻）；
   - 四暗刻 20 番：4 组全为暗刻/暗杠，**取高不叠加三暗刻**；
   - `anke` 组不占 `structure`，因此可与对对胡（10 番）累加：对对胡 + 三暗刻 = 20，对对胡 + 四暗刻 = 30。
6. **十三幺**（`quan`，100 番）：东南西北中发白 + 一万九万 + 一筒九筒 + 一条九条，共 13 种各一张，**其中任意一张再配一张同牌成将**，14 张成胡。
   - 与 `quan` 组其他项（全幺/全文字及其七对形态）取最高，不叠加；
   - 十三幺必然门清，计门清 1 番；
   - 将牌必为幺/字，**判"幺将"将牌番 1 番**；
   - 独赢**不另计**（听牌必然单吊，避免重复）；
   - 合计 = 100 + 1（将牌）+ 1（门清）= **102 番**。

### 6.4 花色类

1. **混一色**（`flush`，20 番）：副露 + 手牌只含一种数牌花色与字牌，且字牌、数牌都至少各 1 张。
2. **清一色**（`flush`，30 番）：只含一种数牌花色，无任何字牌。
3. **全幺**（`quan`，50 番）：全部由 1、9、字牌组成，且**至少含一张 1 或 9**（纯字牌走全文字 100）。
   - 与 `structure` 组互斥：不再另计对对胡/七小对（七对形态用全幺七对 60）；
   - **可与混一色累加**：全幺 + 混一色 = 70 番；
   - 可叠加将牌（1）、独赢（1）、门清（1）、三暗刻（10）/四暗刻（20）、天胡/地胡等非 `quan`/`structure` 番种，例如全幺 + 混一色 + 四暗刻 = 90。
4. **全幺七对**（`quan`，60 番）：全幺手牌 + 七对结构。取代"全幺 + 七小对"的累加。
5. **全文字**（`quan`，100 番）：全部字牌，碰碰胡式（4 刻 + 将）；与 `structure` 组互斥（不另计对对胡）。
   - 将牌必为字牌 → 恒计将牌 1 番，**基准 101**；
   - 可再叠门清（+1）、三暗刻（+10）/四暗刻（+20）、独赢（单吊或嵌张成胡，+1）；
   - 例：全文字 + 四暗刻 = 120，再门清 + 单吊 = 122。
6. **全文字七对**（`quan`，120 番）：全部字牌 + 七对结构；七对不判将牌番，可叠门清与独赢（+1 → 121）。
7. **缺门**（1 番，不占组）：整手牌（含副露）在万/筒/条 中至少缺一门（出现的数牌花色 ≤ 2 种），字牌不参与判定；**命中 `flush` 或 `quan` 组时一律不计缺门**。
   - 正例：`123 万 456 万 789 筒 555 筒 东东` → 缺条，缺门 1 番（未成混一色，因含两门数牌）；
   - 反例：清一色、混一色、全幺、全文字、十三幺 → 0 番（不再追加缺门）。

> 全文字与全幺的区分：纯字牌只记全文字（100），全幺要求手牌含 1/9。包牌判定同样依赖该区分（§7.1）。

### 6.5 时效类

1. **天胡**（100 番）：庄家起手 14 张即胡，牌墙未动、无人出牌。
2. **海底捞月**（100 番）：**牌墙最后一张恰好是 1 筒**，且摸到这张牌的人自摸胡。
   - 牌墙最后一张不是 1 筒 → 本局不产生海底捞月，任何人摸最后一张自摸都只有普通番；
   - 该张被杠后补牌（牌尾）取走并胡，同样成立，且与杠上开花叠加；
   - 若最后一张是 1 筒但摸者未胡 → 不产生。
3. **杠上开花**（10 番）：杠（明/暗/补）后从牌尾补牌自摸胡。
4. **抢杠胡**（10 番）：他人**明杠**（大明杠）时，以该张牌胡，被抢者的杠作废；**不按点炮结算**（不产生点炮者角色），因此也不可能触发包牌。付款按 §3.3 的抢杠胡一行。
   - **只有明杠可被抢**：第 4 张来自他人打出，杠家声明明杠后开放抢杠窗口，其他家以该张胡即抢杠胡；无人抢才成杠。
   - **补杠不可抢**：碰后摸到第 4 张加杠**直接成立**，不开放窗口；照常计补杠 1 分并从牌尾补牌。
   - **暗杠不可抢**：暗杠不开放窗口。
   - 同一张牌上「抢杠胡」优先于「碰/吃」；被抢的杠未成立 → 不计杠分。
   - 判定顺序：第 4 张打出入询问窗口 → 有家声明**明杠**后开抢杠窗口 → 有人以该张胡即抢杠胡；胡家过或无人可胡则明杠成立并计杠分。**无人声明杠**时，同一张牌被胡按**点炮**处理（不计抢杠番、按包牌规则判定）。

### 6.6 门清

无吃、无碰、无明杠；**暗杠不影响门清**。天胡、地胡不叠加门清。

### 6.7 将牌

将（雀头）为 **2、5、8、1、9 或任意字牌** 时成立，1 番：

- 适用：任何 "4 组面子 + 1 将" 的解（含平胡、对对胡、普通胡），**13不靠 也判**（其将牌同样按 258将/幺将 计）；
- 七小对不判将牌番（7 对没有"将"，含全文字七对、全幺七对）；
- 十三幺不判（§6.3.6，将牌为牌型固有形态）；
- 将牌为 3、4、6、7 → 0 番；
- 一副牌只有一个将，故只计 1 次。

例：`234 万 + 567 筒 + 888 条 + 123 万 + 55 筒` → 将牌 5 筒，+1 番。

### 6.8 独赢

胡张形态为以下三种之一时成立，1 番：

| 形态 | 定义 | 例 |
| --- | --- | --- |
| 嵌张（卡张） | 中间张成顺，两侧已在手 | `1_3` 赢 2 |
| 单吊将 | 只等将牌成对 | 4 组面子已定，`_5` 赢 5 作将 |
| 单边（边张） | 只差一侧端张 | `89` 赢 7、`12` 赢 3 |

- **两面不算独赢**（`23` 赢 1/4、`56` 赢 4/7）。
- 与**平胡互斥**：平胡要求"两面听 + 将非幺非 258"，故平胡手不会同时命中独赢。
- 七小对、十三幺不判独赢；**例外：全文字七对按用户口径允许累加独赢**（§6.4.6）。
- 同时满足多种形态（如单边又单吊）仍只计 1 次。

## 6.9 风刻（门风刻 / 圈风刻）

| 番种 | 番 | 判定 |
| --- | --- | --- |
| `men_feng_ke` 门风刻 | 1 | 胡牌者**座风**的刻子或杠 |
| `quan_feng_ke` 圈风刻 | 1 | 本局**局风**的刻子或杠 |

- 门风由**庄家**决定（庄家 = 东风，逐局转动）；局风由**局序**决定（第 1 局 = 东风）。口径见 [03 §3.4](03-规则族设计.md) 与本文 §4。
- 刻子包含：碰出的明刻、暗刻、明杠、暗杠、补杠（杠按刻子计，与 §6.1 一致）；4 张同牌只算 1 个刻子，不因杠而重复计。
- 两项**不互斥**，可叠加至 +2：庄家（门风东）在第 1 局（局风东）胡牌并持东刻子 → 门风刻 1 + 圈风刻 1 = 2 番。
- 风牌**将（对子）不算刻子**；单吊风牌将只计 `jiang_pai` 1 番（若成立），不计风刻。
- 不占 `structure` / `anke` / `long` / `flush` / `quan` / `first` 任何互斥组，可与对对胡、暗刻、混一色、清一色等自由累加。
- 例：门风为南的玩家在东风局胡牌，持南南南 + 东东东 → 门风刻 1（南）+ 圈风刻 1（东为局风）= 2 番；若庄家（门风恒东）在东风局持东东东 → 东刻子同时命中两项，仍为 2 番。

## 6.10 箭刻

中（`zhong`/31）、发（`fa`/32）、白（`bai`/33）三种箭牌，**每有一种成刻子或杠即 1 番**：

| 项 | 规则 |
| --- | --- |
| 计数口径 | 按「种」计：中刻 1 + 发刻 1 + 白刻 1 = 3 番；只有两种 = 2 番；一种 = 1 番；最多 3 番 |
| 刻子范围 | 碰出的明刻、手里三张的暗刻、明杠、暗杠、补杠**都算**（杠按刻子计，与 §6.1 一致） |
| 将牌 | 箭牌作**将（对子）不算刻子**，只按 `jiang_pai` 计 1 番（§6.7） |
| 互斥 | **不占任何互斥组**，可与三暗刻/四暗刻、对对胡、全文字/全幺、混一色、独赢、将牌等自由累加 |
| 不适用 | 七小对（结构里没有刻子）、十三幺、13不靠 不判 |

- 例：`中中中 + 发发发 + 白白白 + 123万 + 55筒` → 箭刻 3（中/发/白 各 1）+ 将牌 1 = 4 番；若同一手为 4 组刻子，另计暗刻番。
- 例：`中中中 + 白白白 + 123万 + 456万 + 99筒`（白为碰出的明刻）→ 箭刻 2（中、白）+ 将牌 1 = 3 番。

## 7. 包牌

### 7.1 触发条件（四条全满足）

1. 胡牌方式为**点炮**（自摸、抢杠不包）；
2. 胡牌者已有 **≥3 组明牌**（吃、碰、明杠各算一组；暗杠不算明牌）；
3. 牌型命中 `清一色 | 混一色 | 全文字 | 全幺`；
4. 点炮的那张牌落在该牌型的允许集内：

| 牌型 | 点炮牌允许集 |
| --- | --- |
| 清一色 | 主花色的数牌 |
| 混一色 | 主花色数牌 或 字牌 |
| 全文字 | 字牌 |
| 全幺 | 1、9 或 字牌 |

同时命中多个牌型时取"任一命中即通过"；纯字牌手牌只按全文字判定（见 §6.4.4）。

### 7.2 结算算法

```
若 触发包牌:
    应付[i] = 按 §3.2 正常计算三家应付
    total   = Σ 应付[非赢家三家]
    付款: 点炮者付 -total，另两家付 0
    赢家收 +total
否则:
    点炮三家各付、自摸三家各付（§3.2）
```

包牌者**不额外翻倍**，其承担的是三家应付款之和（已含各自倍率）。

### 7.3 伪码

```python
def settle(winners, config, dealer_seat, win_type, discarder_seat, exposed_melds, patterns, payers):
    fan_total = evaluate_fan(...)                      # §5 §6
    unit = config.base_score * fan_total
    dues = {seat: unit * mult(seat, winner, dealer_seat, win_type) for seat in payers}

    bao = (win_type == "discard"
           and len(exposed_melds) >= 3
           and patterns & {"qing_yi_se", "hun_yi_se", "quan_zi", "quan_yao"}
           and is_allowed_tile(discard_tile, patterns))

    if bao:
        total = sum(dues.values())
        delta = {s: 0 for s in seats}
        delta[discarder_seat] -= total
        delta[winner] += total
        allocation = {"reason": "bao_pai",
                      "bao_pai_seat": discarder_seat,
                      "covered": [s for s in payers if s != discarder_seat],
                      "amount": total}
    else:
        ...
    assert sum(delta.values()) == 0
```

### 7.4 反例（不包）

- 只有 2 组明牌的清一色点炮胡；
- 自摸清一色，即使 3 组明牌；
- 3 组明牌混一色，但点炮牌是另一门花色；
- 3 组明牌对对胡（非四种牌型之一）；
- 纯字牌手牌，别人点炮 9 万（不在全文字允许集内）。

## 8. 杠分

三类杠的定义（后文「发生过杠」一律指这三类）：

| 杠型 | 怎么来的 | 备注 |
| --- | --- | --- |
| 明杠（大明杠） | 别人打出一张，自己手里已有 3 张同牌，直接杠 | 放杠者即打牌的人；**可被抢杠胡**（声明杠后开放窗口，§6.5.4） |
| 暗杠 | 自己手里凑齐 4 张同牌，扣下成杠 | 暗杠不影响门清（§6.6）；**不可被抢杠** |
| **补杠（加杠）** | 之前**碰**过某张牌（明刻），后来又**摸到第 4 张**，把这张加到原刻子上组成杠 | 属明杠类；**不可被抢杠**，直接成立并计分补牌（§6.5.4） |

| 杠型 | 分值 | 付款方 |
| --- | --- | --- |
| 明杠 | 1 | 三家各付 |
| 暗杠 | 2 | 三家各付 |
| 补杠 | 1 | 三家各付 |

- 杠分**不受**自摸/庄家倍率影响，不计入 `U`，单独累加到 `score_delta`；
- 杠分不占番（番表无 `gang` 项，避免与杠分重复计）；
- 杠后补牌从**牌尾**取（与海底捞月判定口径一致，§6.5.2）。

## 9. 荒庄与暂停

- **荒庄**（牌墙取尽仍无人胡）按本局是否发生杠二分，与 [03 §3.6](03-规则族设计.md) 一致：
  - **有杠**（明杠、暗杠、补杠均算）→ 记荒庄并落库：`winnerSeat=null`、`is_draw=true`；不罚分、不结算番分，已即时结算的杠分保留不回滚；局号 +1、庄家迁下家、局风 +1。
  - **无杠** → 本局作废重发：不落库、不结算，座位/庄家/局风/局号全部不变，广播 `event.round_restarted`。
- **海底优先**：最后一张恰为 1 筒且摸者自摸胡时按胡处理（§6.5.2），不判荒庄。
- **圈结束**：座位 3（北位）庄家这一局结算完成（含荒庄）即本圈结束，下一圈重新抽座；北位这局若「无杠重发」，则该局未结算，圈未结束，继续重发同一局。
- **暂停**：任一在座玩家可发起 `room.pause` / `room.resume`；暂停期间冻结一切倒计时、不接受出牌、不因断线踢人；恢复后从暂停点继续（无计时则无影响）。

## 12. 冻结状态

无待确认项。最后一轮决策：

| 编号 | 事项 | 结论 |
| --- | --- | --- |
| Q1 | 抢杠胡付款 | **S1：仅明杠可被抢（补杠、暗杠不可抢）**；三家各付、不乘自摸倍数，不产生点炮者角色，不触发包牌 |
| Q2 | 全幺是否叠加缺门 | **不叠加**；缺门对 混一色/清一色/全文字/全幺 一律不计 |
| Q3 | 座位与庄家 | 每圈抽座一次，圈内座位不变；第 `n` 局庄家 = 座位 `n-1`，**不连庄**；北位庄家下庄即圈结束（最少 4 局） |
| Q4 | 荒庄 | **有杠**（明/暗/补）记荒庄、迁庄、计 1 局；**无杠**重发本局，不计局、庄家与局风不变 |
| Q5 | 风刻加番 | 门风刻 1 + 圈风刻 1，可叠加至 2 番；不占任何互斥组 |
| Q6 | 箭刻（2026-10-29 追加） | 中/发/白 **每种**一个刻子或杠各 1 番、最多 3 番；计数型、不占互斥组、与暗刻等全部可叠加；杠按刻子计 |

实现时需固化的推论：

- 番表 **32 项全部确定**（`gang` 不占番，只计杠分）；门风刻 / 圈风刻 各 1 番、可叠加；箭刻 1 番/种、最多 3 番；
- 一般高 1 番（**异花色**）、姊妹花 2 番（**同花色**）、三姊妹 3 番（同花色三副，固定番值）；
- 对对胡 10 番；三暗刻 10 番 / 四暗刻 20 番 取高，且可与对对胡累加（对对胡+三暗刻=20、+四暗刻=30）；
- 全幺 50 番，可与混一色累加（70），与 `structure` 组互斥；全幺七对 60 番；
- 全文字 100 番（碰碰胡式，不叠对对胡），+ 将牌 1 = 基准 101，可叠暗刻（四暗刻 → 120）与门清/独赢；全文字七对 120 番（七对不判将牌），可叠独赢（121）；
- 十三幺 100 + 幺将 1 + 门清 1 = 102；不判独赢；
- 13不靠 只与 `structure` 互斥，将牌（258将/幺将）、一般高、混龙等照常判定累加；
- 平胡 = 无碰/无刻/无杠 + **两面听** + 将 3/4/6/7；独赢 = **嵌张 / 单吊 / 单边**（89 赢 7、12 赢 3）；两者互斥；
- 门清 1 番可单独构成 1 番起胡；平胡手 = 平胡 1 + 门清 1 = 2 番；
- 天胡/地胡不叠加门清；
- 缺门对 `flush`（混一色/清一色）与 `quan`（全幺/全文字/全幺七对/全文字七对/十三幺）全抑制；
- **有碰 + 将 3/4/6/7 + 两面听** 这类手牌仍是 0 番，不能胡（起胡 1 番）；
- 补杠 1 分、明杠 1 分、暗杠 2 分，三家各付；
- 抢杠胡只能抢**明杠**（补杠、暗杠不可抢），10 番、三家各付、不乘自摸、不触发包牌；被抢的明杠作废且不计杠分；
- 连6 含 456789；一圈最少 4 局（北位庄家下庄结束），局风随局序 东南西北。
- 庄家轮转：第 `n` 局庄家 = 座位 `n-1`，不连庄；荒庄有杠才计局并迁庄，无杠重发不计局。
- 发牌：每人 4 张 × 3 轮 = 12 张；庄家跳牌取第 1、第 5 张（14 张），闲家各 13 张，首轮庄家直接出牌。

## 13. 验收用例

1. 对对胡 + 清一色 → `fan_total=40`，`U = base × 40`（累计，非乘积）。
2. 闲家自摸 41 番、底分 1 → 庄家 `-164`，两闲 `-82`，`Σ=0`。
3. 庄家自摸 20 番 → 三家各 `-80`。
4. 闲家点炮胡 20 番（未包）→ 庄 `-40`、另两家 `-20`。
5. 3 明牌清一色点炮胡 40 番 → 点炮者独付 `-160`，另两家 `0`，`Σ=0`。
6. 自摸同牌型 → 不包，三家各付。
7. 牌墙最后一张为 1 筒且摸者自摸胡 → 番表含 `hai_di_lao_yue` 100；换任意其它牌 → 不含。

14. 对对胡 + 三暗刻 → 20 番；对对胡 + 四暗刻 → 30 番；四暗刻不再叠加三暗刻。

16b. 补杠不可抢：B 碰过 X 后摸到第 4 张 X 加杠 → 直接成杠、计补杠 1 分、牌尾补牌，不产生 `rob_kong` 询问，他人不能以该张胡。
16c. 暗杠不可抢：D 暗杠后不开放抢杠窗口，不产生 `rob_kong` 询问。
17. 将牌番：将 5 筒 / 东 各 +1 番；将 3 万 → 0 番；七小对不判，13不靠判。
18. 一般高 123万+123条 → 1 番；姊妹花 123万+123万 → 2 番；三姊妹 123万×3 → 3 番（固定番值，不再叠姊妹花/一般高）。
19. 平胡：`123万 456万 789万 234条 + 33万`（将 3 万、听两面 1/4 条）→ 平胡 1 + 门清 1 = 2；将换成 55 万 → 平胡不成立（将 5 属 258），改计将牌 1 番。
20. 独赢：听嵌张（`1_3` 等 2 万）、单吊将、或单边（`89` 赢 7、`12` 赢 3）→ 各 1 番；两面（`23` 赢 1/4）不算；平胡与独赢不可同时命中。
21. 全幺 50；全幺 + 混一色 70；全幺 + 混一色 + 四暗刻 90；全幺七对 60（不再叠对对胡/七小对）。

24. 一般高/姊妹花 每对计一次：`123万×2 + 123条` → 姊妹花 2（万-万）+ 一般高 1×2（万-条）= 4。
25. 风刻叠加：庄家（门风东）在第 1 局（局风东）胡牌且持东刻子 → 门风刻 1 + 圈风刻 1 = +2 番；同一手改持南刻子 → 0 番；第 2 局庄家持东刻子 → 仅门风刻 +1。
26. 风刻跨风：门风为南的玩家在东风局胡牌，持南南南 + 东东东 → 门风刻 1（南）+ 圈风刻 1（东）= 2 番。
27. 风刻不认将：风牌只剩一对（如东东作将）→ 不计门风刻/圈风刻。
28. 荒庄无杠：牌墙取尽且全程无杠 → 不落库、`round_no`/`dealer_seat`/`round_wind` 不变；重发后仍为该局。
29. 荒庄有杠：本局有明杠后牌墙取尽无人胡 → `winnerSeat=null`、`is_draw=true`、杠分保留、不罚分；下一局 `dealer_seat+1`、`round_wind+1`。
30. 发牌：庄家 14 张、闲家各 13 张；跳牌取取牌序列第 1、5 张，南西北依次取第 2、3、4 张。
31. 箭刻：`中刻+发刻` 两个明碰 + 白将 → 箭刻 2 + 将牌 1；`中刻+发刻+白刻` → 箭刻 3；单一箭刻（含明杠/暗杠/补杠）→ 1 番；箭牌作将不算刻子；可与三暗刻/四暗刻、全文字、对对胡叠加（如全文字 + 三箭刻 + 将牌 = 100+3+1 = 104）。
