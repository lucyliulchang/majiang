互斥组说明：

  • structure：平胡 / 对对胡 / 七小对 / 13不靠 只取最高。
  • anke：三暗刻 / 四暗刻 只取最高（四暗刻为上位，不叠加三暗刻）。
  • long：青龙 / 混龙 取最高，青龙为上位。
  • flush：混一色 / 清一色 只取最高。
  • quan：十三幺 / 全文字 / 全文字七对 / 全幺 / 全幺七对 只取最高；命中 quan 组时 structure 组不计（这些牌型的番值已含碰碰胡/七对形态）。
  • flush 与 quan 可以同时成立：全幺 + 混一色 = 70 番。
  • first：天胡 / 地胡 / 门清 互斥，取最高；天胡、地胡不再叠加门清。
  • 缺门 被 flush 与 quan 双向抑制：命中任一组的牌型一律不计缺门。
  • 三姊妹 命中时，其 3 副顺子不再计 一般高 / 姊妹花；其余顺子照常。
  • 缺门、将牌、独赢 不属任何互斥组，恒可累加；三暗刻/四暗刻 自成一族（anke），只与彼此互斥、不占其它组；缺门、将牌、独赢、暗刻各只计一次。
  • men_feng_ke / quan_feng_ke 不属任何互斥组，各计一次、可互相叠加；同一局两者可能指向同一张牌（庄家在第 1 局持东刻子），此时计 2 番。
  • jian_ke（箭刻）为计数型：中、发、白 各算一种，每命中一种计 1 番，最多 3 番；不属任何互斥组，可与暗刻、对对胡、全文字/全幺、混一色等自由累加。
  • er_wu_ba_ying（258赢）看最后赢张、jiang_pai（将牌）看雀头，两者独立判定、可同时成立：将 5 筒 + 赢 8 万 = 2 番；同一手只计一次，不因多解重复。
  • duan_yao（断幺）与 quan 组天然互斥（全幺/全文字/十三幺必含幺九或字牌）；与 flush 的 qing_yi_se 可叠加（清一色断幺 = 31），与 hun_yi_se 天然冲突（混一色必含字牌）。
  • yi_zhi_yao（一只幺）与 duan_yao（断幺）天然互斥（断幺 = 0 张幺牌，一只幺 = 1 张幺牌）；与 quan 组天然互斥（十三幺/全幺/全文字必含 ≥2 张幺牌）；不占任何互斥组，与 jiang_pai、du_ying、men_qian、que_men 等自由累加；幺牌为字牌时可与 hun_yi_se（混一色）并存。
  • 其余番种均可与任何不同组番种累加；同 id 按"组"各计一次。

7.1 触发条件（四条全满足）

  1. 胡牌方式为点炮（自摸、抢杠不包）；
  2. 胡牌者已有 ≥3 组明牌（吃、碰、明杠各算一组；暗杠不算明牌）；
  3. 牌型命中 清一色 | 混一色 | 全文字 | 全幺；
  4. 点炮的那张牌落在该牌型的允许集内：
牌型点炮牌允许集
清一色主花色的数牌
混一色主花色的数牌（字牌不算）
全文字字牌
全幺幺牌 = 1、9 数牌 或 字牌

同时命中多个牌型时取"任一命中即通过"；纯字牌手牌只按全文字判定（见 §6.4.4）。

v1.13 修正（2026-11-07 生产反馈）：flush 组（混一色/清一色）只认主花色的数牌，

字牌点炮不包——原实现把字牌也算作混一色的允许集，属规则错误。

quan 组不受影响：全幺的幺牌 = 1/9 数牌 + 字牌（两者点炮都包），全文字只认字牌。
