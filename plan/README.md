## 术语表

| 术语 | 含义 |
| --- | --- |
| family / 家庭 | 独立实体（`mj_family`），成员通过 `mj_family_member` 归属；房间、规则模板、自定义皮肤按家庭隔离 |
| 规则族 / rule family | 玩法族（`mj_rule_family`），决定引擎插件与可用开关；**全局**，与 family 无关 |
| 规则模板 | 族内参数预设（`mj_rule_template`），开桌时只选模板，不直接编辑快照 |
| 规则快照 | 开桌/开局时把「族 + 模板 + 生效配置」冻结进 `mj_room.ruleSnapshot` / `mj_game.ruleSnapshot`，此后不可变 |
| 柏氏规则 | 一个全局规则族（`ruleFamilyCode = baishi`），细则已冻结于 [07-柏氏规则细则.md](07-柏氏规则细则.md) |
| 皮肤 / skin | 一整套 34 张牌 + 牌背图片资源，含全局内置与家庭自定义两类 |
| 音效 / SFX | 由 WS 增量事件触发的短音频（出牌/吃/碰/杠/胡/摸牌等）；**只有 SFX，没有 BGM** |
| 邀请码 | 6 位纯数字（100000–999999），全局唯一，用于入房 |
| 座位快照 | 按查看者座位或观战目标生成的 `state.snapshot`；只给本人或观战目标的手牌明文 |
| 观战跟随 | 满座后观战者只跟随 1 名在座玩家；每名在座玩家最多 10 名观战者（4×10=40）；关系只存内存、不落库 |
| 258 赢 | 最后赢张为数牌 2/5/8 的番种（1 番），看赢张不看将牌，与「将牌（258 将）」是两件事 |
| 断幺 | 整手牌（含副露）无 1/9 数牌、无任何字牌的番种（1 番） |
| 过胡 | 询问窗口内对「胡」选择放弃；v1.1.0 口径为**仅当前这张牌**生效，过胡后才补发吃碰杠选项 |
| 收桌 / 关房 | 房间收尾：`mj_room.roomStatus` 置 `CLOSED`、广播 `event.room_closed`、演员从注册表移除；大厅只列 `OPEN` |
| 圈 | 4 个庄次（东南西北各坐一次庄为一圈）；北位庄家下庄即本圈结束，换圈不重抽座 |
| 场 | 一场 = N 圈（`circles_per_game`，默认 4、开桌可选 1/2/4/8）；打满圈数收场，连庄会让实际局数多于 N×4 |

## 维护规则

1. 改表结构：先改 `02-数据库设计.md` 的字段表，再改 `database/*.txt`，最后跑生成器与合并工具。
2. 改接口：先改 `04-协议设计.md`，再改 `code/backend/src/main/` 与 `code/frontend/src/api/`。
3. 改规则：先改 `03-规则族设计.md` 的族能力声明与模板 schema，再改引擎插件。
4. 改音效：先改 `08-音效设计.md` 的触发映射与资源规格，再改 `src/audio/` 与 `public/audio/sfx/`。
5. 任一步实施完成，回写对应文档的"验收清单"与状态。
6. 改观战：先改 00 §4.3/§9、04 §9、05 §4.5，再改 `realtime/` 与前端；观战关系不落库、不新增表。
