## 2. 规则语义（v1.16）

包牌五条全满足才成立：

1. 点炮（自摸/抢杠不包）；
2. 赢家已有 ≥3 组明牌；
3. 牌型命中 `清一色 / 混一色 / 全文字 / 全幺`；
4. 点炮牌落在该牌型的允许集（v1.13：混一色/清一色只认主花色数牌，字牌不算）；
5. **该牌型的特征牌已经出现在明牌里**（v1.16）：
   - 清一色 / 混一色 → 明牌至少一张**主花色数牌**（明牌全是字牌 ⇒ 不包）；
   - 全文字 → 字牌、全幺 → 幺牌（这两类手牌本身全字牌/全幺，恒成立）。

本局（明牌 碰西/碰发/碰中 + 混一色筒 + 点炮一筒）按新口径 → **不包**，三家各付。
