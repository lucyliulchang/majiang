## 4. 遗留问题与后续

1. **生产番表仍是 34 项**：仓库已推进到 35 项（I9 一只幺 / I10 13不靠 不计门清独赢），代码在工作区未发布；下一轮发版需重跑 `seedPresets` 并复核 `baishi_default.fan_table = 35`。
2. **14 号清理脚本按 recID 白名单**：本次用了 `REC_IDS=4,5,6,8`；长期看应改为「`roomStatus='OPEN'` 且对应场次非 PLAYING」的状态匹配，避免每次人工填白名单。
3. **发版窗口**：本次为用户明确授权在有对局时重启（牺牲 room 8 第 3 局）。后续仍应按 07 §7 避开对局时段。
4. **手机端单独构建**：`npm run build` **不含**手机端，需 `npm run build:mobile` 并分别上传 `dist` / `dist-mobile`；手机端资产「只增不删」以免老页面 404。
5. **并行的 I9–I12 未纳入本次发布**：一只幺、13不靠 判番调整、牌面人声报牌（S-1）、结算页胡张标记（V-1）仍在进行中；其中 S-1/V-1 涉及前端与协议，需要单独回归与发版。
6. **未验证项**：本轮未覆盖「断网兜底关房」「满座围观上限」「皮肤切换」在生产的表现（I6 已在测试环境覆盖）；四圈一整场（16 局）的长时间牌局未在生产跑完。
