## 3. 视觉定义

**牌面本体**：纵向渐变 `#FFFDF7 → #EDE6D1`，1px 内描边 `#DBCEB3`，双层内阴影（底部深、顶部亮）模拟象牙牌的倒角凸起；所有牌共用同一套材质参数，保证并排摆放时厚度一致。

**刻纹配色（传统三色）**

| 花色 | 颜色 | 说明 |
| --- | --- | --- |
| 万 | 数字 `#141C18` ／ 萬 `#C0392B` | 上数字下红萬，与参考实拍牌一致 |
| 筒 | 青 `#2A6E8F` · 玉 `#2E7D5B` · 朱 `#C0392B` | 圆点 = 外环 + 实心点，按传统点位排布 |
| 条 | 玉 `#2E7D5B`（7s 顶节朱红） | 竹节竖条，双刻线分三段 |
| 字牌 | 东南西北 `#141C18` · 中 `#C0392B` · 發 `#2E7D5B` · 白 留白 + 金细框 | — |
| 牌背 | 渐变 `#123A2B → #071A12`，双金框 `#C9A063` + 菱形徽记 | — |

**字体**：Noto Serif SC Bold（牌面汉字、万子数字），字重与 186px 视觉重心对齐。

## 4. 重新出图

源稿是一张 192×288 的矢量画布，每张牌一个顶层 Frame（Frame 名即 `tile_key`），牌面图案由 SVG 矢量或文本节点构成，可直接改色 / 改点位 / 换字体。

改动后的流程：

1. 在源稿里选中对应 Frame → 导出 PNG（1×，即 192×288）；
2. 若导出为索引色 PNG（Ardot 默认输出 PLTE+tRNS），跑一次归一脚本转真彩 RGBA：

```bash
python tools/normalize_preview.py
```

3. 脚本同时会重算 `preview.png`。

> 为什么必须归一：索引色只有 256 色，牌面纵向渐变会出现明显色带，且部分图像库（含部分 WebP 转换链）对 tRNS 处理不一致。转 RGBA 后渐变连续、透明通道无歧义。

## 5. 前端回退

35 张全量命中时走图片；任一张缺失或 `onerror` 时该张回退 CSS 牌面（05 文档 §6.3）。牌背无图时回退深绿渐变 + 金边，与本套 `back.png` 视觉一致，切换无跳变。
